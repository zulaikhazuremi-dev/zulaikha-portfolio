# Zulaikha Zuremi — Developer Portfolio

A responsive static portfolio built with HTML, CSS, Bootstrap and JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser.
3. An editor extension such as Live Server is optional — it is not required.

## Before publishing

- Replace the placeholder LinkedIn and GitHub links with your actual profile URLs.
- Review the contact details you want to publish publicly.
- Do not upload company source code, credentials, internal URLs, confidential documents, or screenshots containing confidential data.
- If you want a public CV button, add a redacted `resume.pdf` to the project and link it from the page.
